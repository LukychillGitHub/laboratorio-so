# Laboratorio de SO

App de práctica para el **2.º parcial de Sistemas Operativos** (USAL, Ingeniería Informática).

**Abrila acá:** https://lukychillgithub.github.io/laboratorio-so/

## Qué tiene

**1 · Leer la teoría**: 26 lecciones en orden, con índice y progreso de lectura.
- **Teoría (10):** procesos y BCP, planificación de la CPU, IPC y sincronización, redes TCP/IP, sistemas de archivos, comparativa de FS, seguridad en Linux, elección de SO, SO en la nube, NPU / tendencias / Tanenbaum.
- **TPs y parcial (5):** parcial anterior resuelto, respuestas modelo de desarrollo y opinión, TP Seguridad en Linux, TP Comandos básicos, TPs de investigación (FS, SO alternativos, Tanenbaum).
- **Comandos (11):** redirección, navegación, find/grep, texto, permisos, sistema, procesos, respaldo, cron, redes, firewall.

**2 · Practicar**: más de 640 preguntas que **no se repiten**: siempre salen primero las que nunca respondiste.
- Práctica por tema, exámenes simulados con nota (completo, de teoría y de comandos).
- Ejercicios generados al azar, que no se terminan nunca: **cuadros de planificación** (FCFS, SJF, SRTF, Round Robin y Prioridades, con el Gantt resuelto), **permisos** y **cron**.
- "Escribí el comando", en una terminal simulada.
- Repaso de lo que erraste al final de cada ronda.

También incluye **`terminal.html`**, una terminal de Ubuntu simulada para hacer los TPs de comandos paso a paso (con laboratorio de flags y multiple choice), **`procesos.html`**, un simulador visual de procesos (BCP, 5 estados, planificador segundo a segundo, condición de carrera y semáforos), **`archivos.html`**, un simulador visual del disco (guardar, abrir y borrar paso a paso, métodos de asignación y journaling), y `guia.html`, la guía resumida con el parcial anterior.

## Instalarla como app

- **Android (Chrome):** abrí el link → menú ⋮ → *Instalar app* (o *Agregar a pantalla principal*).
- **iPhone (Safari):** abrí el link → botón Compartir → *Agregar a inicio*.
- **PC (Chrome/Edge):** ícono de instalar en la barra de direcciones.

Funciona sin conexión después de abrirla una vez. Tu progreso queda guardado en el navegador del dispositivo.

## Publicarla con GitHub Pages

Settings → Pages → *Deploy from a branch* → `main` / `(root)` → Save.
